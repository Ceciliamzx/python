# Project Manager

## 名词
1. 移测、上车
2. excel：发布流程、紧急预案
3. 回滚、灰度、AB test
4. Jira、Confluence 文档工具
5. 分支、窗口、流水线、生产、预发布

## 环境和发布流程
dev -> test -> product (master/main)

product rollback: test-v1 ==> test-v2 ==故障发生==> test-v1



product manager 对product负责,关注 用户、需求、竞品

project manager 对project负责,关注 窗口、分支、流水线
